# Faye_Pivlot

## yoga_grid —— 从瑜伽练习视频抓正位帧，拼成九宫格

给一支十几分钟的练习视频，输出一张 3×3 的九宫格图：九个不同体式，每个取该体式做得最到位的那一帧。

```bash
python -m yoga_grid 我的练习.mp4
```

完全离线运行，不上传视频，不调用任何外部 API。

---

## 安装

```bash
pip install -r requirements.txt
```

Linux 上 MediaPipe 还需要两个系统图形库（macOS / Windows 不需要）：

```bash
sudo apt-get install -y libegl1 libgles2
```

首次运行会自动下载约 9 MB 的姿态模型到 `~/.cache/yoga_grid/models/`，之后复用。

---

## 用法

```bash
# 最简：出一张 2048×2048 的九宫格到 ./out
python -m yoga_grid 练习.mp4

# 指定输出目录和尺寸
python -m yoga_grid 练习.mp4 -o 今天 --size 3000

# 抽帧更密（慢一些，短暂的保持也能抓到）
python -m yoga_grid 练习.mp4 --interval 0.3

# 不想要山式（避免过渡时的站立占掉一格）
python -m yoga_grid 练习.mp4 --exclude mountain

# 看看内置了哪些体式模板
python -m yoga_grid --list-poses
```

十分钟 1080p 的视频在普通笔记本 CPU 上大约 2–4 分钟，瓶颈是姿态估计。

### 换掉某一格

自动挑的九张不一定都合心意。`candidates/` 里是所有候选帧（文件名带时间、体式、画质分，入选的带 `_PICK`），`scores.json` 里是它们的完整分数。改法：

1. 把不想要那张的 `selected` 改成 `false`；
2. 挑一张想要的，`selected` 改成 `true`，`grid_slot` 设成腾出来的格号（0–8）；
3. 重拼，不用重跑整条流水线：

```bash
python -m yoga_grid grid out
```

## 工作原理

四层过滤，从最可靠的信号开始。

**① 保持段检测** —— 正位几乎只出现在体式稳住的那几秒，过渡动作都在快速移动。按 0.5 秒抽帧后，用关键点的移动速度找出低速窗口。这是最可靠的一层：判断「动没动」比判断「姿势对不对」稳得多，能把上千帧砍到几十段，几乎不误杀。

速度由两部分相加：**姿态速度**（髋心归一化后主干关键点的位移，反映肢体构型变化）和**整体速度**（髋中点自身的位移，反映人在移动）。只算前者，「保持同一姿势往后退一步」会被误判为静止；只算后者，原地挥臂会被误判为静止。

阈值默认自适应——取速度分布的 30 分位数，因为流瑜伽和阴瑜伽的节奏差异很大，固定阈值不通用。

**② 画质筛选** —— 每个保持段内挑关键点置信度高、人体完整入画、不模糊的帧。清晰度用同一视频内的**分位排名**而非拉普拉斯方差绝对值，后者随分辨率和光线大幅漂移，没有可比性。

**③ 体式识别与正位打分** —— 一组基于关节角度的规则模板（见下）。每项检查测一个几何量并和目标值比对，误差在容差内给满分、超出后线性衰减到零。

模板还带一个**躯干朝向门槛**：脊柱方向的竖直分量（+1 直立、0 水平、−1 倒置）必须落在该体式允许的区间内，否则整个模板分乘以一个衰减系数直至归零。这一层不可省——判断「竖直」的常规做法要取绝对值，分不出直立和倒立，会把肩倒立判成山式。

**④ 聚类去重与选帧** —— 按归一化骨架距离做平均连接层次聚类，再把主导体式相同的簇合并（骨架聚类会因机位角度把同一体式拆成两簇，不合并的话九宫格里会出现两个下犬式）。左右版本的同一体式默认算同一个（`--mirror-distinct` 可分开）。

然后**两级排序，刻意用不同依据**：

- **簇内**（同一体式挑哪一帧）按正位分——同体式共用一套模板，分数可比；
- **簇间**（哪九个体式进九宫格）按画质分与保持时长，**不用**正位分。不同体式的模板宽严不一，横向比较会系统性偏袒容差松的体式，还会把没识别出体式的帧一律挤掉。

体式种类不足九个时，用已入选体式的另一次保持补位（要求时间上间隔至少 8 秒），并在 `report.md` 里标注为「同体式补位」。

## 内置体式模板

| key | 体式 | 对称性 |
|-----|------|--------|
| `downdog` | 下犬式 | 对称 |
| `plank` | 平板式 | 对称 |
| `warrior1` | 战士一式 | 左右 |
| `warrior2` | 战士二式 | 左右 |
| `warrior3` | 战士三式 | 左右 |
| `triangle` | 三角式 | 左右 |
| `tree` | 树式 | 左右 |
| `bridge` | 桥式 | 对称 |
| `child` | 婴儿式 | 对称 |
| `mountain` | 山式 | 对称 |

**识别不出的体式不会被丢掉**——它们照样按画质和保持稳定性参与九宫格竞争，只是标签显示「未识别体式」、没有正位分。所以练了模板之外的体式也不会漏。

加新体式就是在 `poses.py` 的 `TEMPLATES` 里加一条：几项 `Check`（测量函数、目标值、容差、权重）加一个 `spine_up` 朝向区间。`Check` 的测量函数通过 `PoseView` 访问关键点，`s_` 前缀表示主侧、`o_` 表示另一侧，同一个模板会自动左右各试一遍取高分，不必为左右各写一份。

## 参数调优

| 症状 | 调这个 |
|------|--------|
| 找不到保持段 | `--min-hold 0.5`，或 `--vel-thresh 0.6` 放宽静止判定 |
| 短暂的保持被漏掉 | `--interval 0.3` 抽密一点 |
| 体式种类偏少、总在补位 | `--cluster-dist 0.25` 分得更细 |
| 同一体式占了好几格 | `--cluster-dist 0.45`，或确认 `--no-merge-same-pose` 没开 |
| 过渡时的站立占了格子 | `--exclude mountain` |
| 裁图切到了头或脚 | 默认就不会切；若用了 `--pad-mode crop`，换回 `blur` |
| 想留人体周围更多环境 | `--pad 1.6` |
| 标签是英文 | 系统缺中文字体，用 `--font /path/to/字体.ttf` 指定 |
| 想更准（慢一倍） | `--model heavy` |

## 局限

- **角度都在图像平面（2D 投影）上算。** 练习者明显斜对镜头时，投影角度会偏离真实解剖角度，正位分偏低。固定机位、身体大致与镜头平面平行时最准。
- **模板只覆盖十个常见体式。** 其余体式能入选但没有正位评分。
- **正位分衡量的是几何对位，不是安全或体感。** 它不知道你的柔韧度、代偿或旧伤，别拿它当教学替代。
- 画面里多人时取外框最大的那个，未必总是练习者本人。

## 关于视觉模型打分

这一版是纯离线的规则实现。原方案里还有一步「用 Claude 视觉对候选帧打分」——它通用性更强（不必穷举体式模板），也能给出文字化的正位反馈。接入点在 `score.py`：`Candidate.alignment` 是唯一被下游消费的正位分字段，`select.py` 的 `_assign_alignment` 是它的唯一写入处。换成视觉模型打分只需替换这一处，选帧、聚类、拼图都不用动。
